# PC の準備

## 1. Git を入れる

Git for Windows を公式のページから入れます。
入れたら、ターミナルで `git --version` と打ち、版が表示されることを確かめます。

## 2. Git の初期設定

ターミナルで、名前とメールアドレスを設定します。
メールアドレスは、GitHub の noreply のアドレスを使います。

## 3. VS Code を入れる

VS Code を公式のページから入れます。
Windows はユーザー向けのインストーラーを使います。
Mac は zip を展開して、アプリケーションのフォルダへ移します。
日本語の表示にする拡張機能も入れます。
